# Snake and Apple

A complete, modern, classic Snake & Apple game implemented in a single HTML file with inline CSS and JavaScript.

## Features

- **Single-file Implementation:** Everything runs directly from `index.html` with no external dependencies or CDN links.
- **Modern Polished Graphics:** Features a dark modern theme with glassmorphism UI, neon glow, and rounded aesthetics.
- **Smooth 60 FPS Gameplay:** Built using `requestAnimationFrame` and positional easing for completely smooth snake movement.
- **Responsive Design:** Optimized for both mobile and desktop screens. It scales dynamically while preserving the aspect ratio.
- **Input Methods:**
  - **Keyboard Controls:** Arrow keys and WASD.
  - **Touch Swipe:** Intuitive swipe-to-move controls for mobile browsers.
  - **Mobile D-pad:** On-screen buttons included for touch fallback.
- **Progress Tracking:** Local high score persistence using `localStorage`.
- **Procedural Sound Effects:** Automatically generated beeps and retro sound effects using the Web Audio API without needing external sound files.
- **Visual Feedback:** Particle systems when eating an apple and breathing/pulsing animations for elements.

## How to Play

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Click **Play Now**.
4. Use your keyboard (Arrow Keys/WASD) or touch swipe on mobile to guide the snake.
5. Eat apples to increase your score and speed up.
6. Avoid hitting the walls or your own tail!
